# Краткое описание продукта

Версия 1.0.0 · 20.09.2026

**«Вовремя»** — мини-приложение MAX для малого бизнеса, которое ведёт сроки лицензий, договоров, сертификатов и медосмотров и заранее напоминает о них сообщениями бота.

| Аспект | Содержание |
|---|---|
| Проблема | Владелец малого предприятия хочет продлевать документы вовремя без отдельной системы учёта, но сроки разбросаны по бумагам и памяти сотрудников и никто не напоминает о них, из-за чего документы истекают незаметно, а бизнес рискует штрафами и приостановкой работы |
| Пользователь | Владелец или управляющий предприятия общепита на 1–3 точки (пилот — Санкт-Петербург); сотрудники с ролями редактора и наблюдателя |
| Ценность | Список всех сроков в одном месте, типовые документы по профилю за 2 минуты, напоминания в MAX за 30/7/1 день с кнопкой открытия карточки, совместная работа |
| Масштабирование | Справочник видов деятельности, регионов, признаков и правил применимости расширяется данными без изменения кода; АПК (техосмотр самоходной техники) уже в справочнике |
| Использование MAX | Запуск из бота и по диплинкам, серверная проверка подписи запуска, сообщения бота с кнопками, шеринг приглашения внутри MAX, кнопка «Назад», подтверждение закрытия формы, сканер QR, скачивание файла, тактильный отклик |
| Форма продукта | Мини-приложение MAX — основной и единственный интерфейс пользователя. Бот — обязательная по правилам платформы точка запуска и канал напоминаний; своих сценариев у бота нет, каждое его сообщение открывает мини-приложение |
| Итоговое решение | Frontend React + MAX UI; backend на Go из двух сервисов (`core`, `bot`) с gRPC между ними; PostgreSQL 18; Caddy; Docker Compose; запуск одной командой |

Ключевой сценарий демонстрации (2 минуты): открыть приложение из чата с ботом → выбрать «Общепит», отметить признаки → получить 9 типовых документов → указать даты → увидеть «просрочено / скоро / в порядке» → через заданное время получить напоминание в чате MAX → нажать «Открыть документ» → продлить.
