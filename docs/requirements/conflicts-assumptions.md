## Ограничения

| ID | Ограничение | Следствие |
|---|---|---|
| L-01 | Один хост Compose | Отказ хоста останавливает систему; RPO = интервал резервного копирования (24 ч), RTO ≈ 1 ч восстановления из дампа |
| L-02 | Нет хранения файлов | Скан документа не прикладывается; допускается ссылка `reference_url` |
| L-03 | Справочник модельный | Юридически значимые сроки не утверждаются; пользователь вводит даты сам |
| L-04 | Доставка напоминаний «хотя бы один раз» | Редкий дубль при таймауте ответа MAX |
