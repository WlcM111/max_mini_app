# Глоссарий и предметная область

Версия 1.0.0 · 20.09.2026

## Предметная область

Малое предприятие (пилот — кафе на 1–3 точки) одновременно обязано поддерживать в силе десятки документов с разными сроками: сертификат электронной подписи, ключ фискального накопителя кассы, лицензию на алкоголь, договоры аренды и вывоза отходов, медосмотры сотрудников, поверку весов, обслуживание огнетушителей. Сроки узнаются из самих документов. Пропуск срока приводит к штрафам, невозможности сдать отчётность или остановке продаж. Владелец ведёт сроки «в голове» или в таблице без напоминаний. «Вовремя» ведёт реестр документов организации, подсказывает типовые документы по профилю бизнеса и заранее напоминает в MAX.

## Термины

| Термин | Определение | Представление в системе |
|---|---|---|
| MAX | Российский мессенджер, среда работы решения | — |
| Мини-приложение (Mini App) | Веб-приложение, открываемое внутри MAX из чата с ботом | `frontend/`, раздаётся `edge` |
| Бот | Учётная запись MAX, через которую работает мини-приложение и отправляются напоминания | сервис `bot` |
| MAX Bridge | JS-библиотека `max-web-app.js`, объект `window.WebApp` | `frontend/src/platform/max/` |
| Данные запуска (initData) | Подписанная строка с данными пользователя, передаваемая MAX при каждом запуске | `SessionCreateRequest.init_data` |
| Диплинк | Ссылка `https://max.ru/<bot>?startapp=<payload>`, открывающая мини-приложение с параметром | `StartTarget`, кнопки бота |
| start_param / payload | Параметр диплинка, до 512 символов `[A-Za-z0-9_-]` | грамматика `doc_`, `org_`, `inv_` |
| Webhook | HTTPS-запросы MAX с событиями бота | `POST /max/webhook` |
| Bot API | HTTP API MAX для ботов на `platform-api2.max.ru` | `bot/internal/adapters/maxapi` |
| Организация | Бизнес пользователя, для которого ведутся документы | `core.organizations` |
| Участник | Пользователь с ролью в организации | `core.memberships` |
| Роль | `owner` (владелец, один), `editor` (редактор), `viewer` (наблюдатель) | `Role` |
| Профиль бизнеса | Вид деятельности, регион, часовой пояс, признаки | `business_category_code`, `region_code`, `timezone`, `feature_codes` |
| Признак | Ответ «да» на вопрос о бизнесе (есть сотрудники, продаёт алкоголь) | `core.features` |
| Тип документа | Запись справочника с описанием, отступами и шагами продления | `core.document_types` |
| Модельные данные | Справочник, не сверенный с нормативными актами | `data_status='model'` |
| Правило применимости | Условие «категория + все признаки», при котором тип документа предлагается | `core.applicability_rules` |
| Документ | Конкретный документ организации | `core.documents` |
| Период действия | Интервал `valid_from`…`valid_until`; у документа один текущий период, прошлые — история | `core.document_periods` |
| Продление | Создание нового текущего периода | `POST /documents/{id}/renewals` |
| Статус срока | `expired` (дата окончания < сегодня), `expiring` (≤ 30 дней), `valid` (> 30 дней), `no_expiry` (бессрочный) | `DeadlineStatus` |
| Отступ напоминания | Число дней до окончания срока, в которое нужно напомнить (0–365, до 5 значений) | `core.document_reminder_offsets` |
| Напоминание | Запланированное сообщение участнику о сроке | `core.reminders` |
| Канал напоминаний | Состояние диалога пользователя с ботом | `RecipientState` |
| Приглашение | Одноразовая ссылка с ролью, срок 72 ч | `core.invites` |
| Сессия | Серверная запись о входе, токен `vvs_…` | `core.sessions` |
| Токен проверяющего | Сессия служебного аккаунта для проверки API | `kind='review'` |
| Outbox / очередь доставки | Таблица исходящих сообщений бота | `bot.outbound_messages` |
| Lease | Временная блокировка строки очереди на время отправки | `locked_until` |
| Ключ идемпотентности | Уникальный ключ, по которому повтор операции не создаёт дубль | `idempotency_key`, клиентский `id` |
| edge | Caddy: HTTPS, статика, прокси | сервис `edge` |
| ICS | Формат календаря iCalendar (RFC 5545) | экспорт сроков |
| КЭП | Квалифицированная электронная подпись | тип `qualified_esignature` |
| ККТ, ФН, ОФД | Касса, фискальный накопитель, оператор фискальных данных | тип `kkt_fiscal_drive` |
| СОУТ | Специальная оценка условий труда | тип `special_labor_assessment` |
| ТКО | Твёрдые коммунальные отходы | тип `waste_removal_contract` |
