# ADR-030: Идентификаторы трассировки без OTel SDK

Статус: принято. Дата: 2026-09-20. Версия архитектуры: 2.0.0.
## Контекст
Требуются `trace_id` и `span_id` в логах и их передача между сервисами.
Экспорт спанов в проекте выключен по умолчанию, а сборка выполняется в среде без доступа к произвольным репозиториям модулей.

## Решение
Идентификаторы формируются собственным кодом по формату W3C Trace Context и передаются
в метаданных gRPC заголовком `traceparent`. SDK OpenTelemetry в reminders-service не подключается.

## Основания
Формат совместим с OpenTelemetry: при включении экспорта идентификаторы не меняются.

## Недостатки
Нет готовых спанов и экспортёра; при включении OTLP потребуется добавить SDK.

## Последствия
Логи всех сервисов сопоставимы по `trace_id`; заголовок принимается от вызывающей стороны.

## Условия пересмотра
Включение OTLP-экспорта — подключение SDK и замена собственной генерации.
