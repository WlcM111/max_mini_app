# ADR-003. Frontend framework

**Вопрос.** На чём строить Mini App?

**Требования.** Кейс рекомендует JavaScript и React; официальная библиотека компонентов MAX UI — React (`@maxhub/max-ui`, MIT, React 18+, F-29); работа в iOS, Android, desktop, web; начальный JS ≤ 200 KB gzip; разработчики знают только Python — нужен стек с максимумом учебных материалов и надёжной генерацией кода AI-агентами; данные запуска приходят во фрагменте URL (F-12).

**Варианты (сравнение по 6 критериям, 1–5).**

| Критерий | React 18 + TS + Vite + MAX UI | Vue 3 + TS + Vite | Svelte 5 + TS + Vite | Next.js (React) |
|---|---|---|---|---|
| Официальные компоненты MAX | 5 | 1 | 1 | 5 |
| Рекомендация кейса | 5 | 2 | 2 | 4 |
| Размер бандла | 3 | 4 | 5 | 2 |
| Материалы и надёжность генерации кода | 5 | 4 | 3 | 4 |
| Статическая раздача без Node-сервера | 5 | 5 | 5 | 2 |
| Сложность для новичков | 3 | 4 | 4 | 2 |
| **Сумма** | **26** | 20 | 20 | 19 |

**Решение.** React 18.3 + TypeScript 5 (strict) + Vite 7 + `@maxhub/max-ui` + TanStack Query v5 + React Router v7 в режиме `createMemoryRouter` + `openapi-fetch` с типами из `openapi-typescript`. Формы — управляемые компоненты и собственные функции валидации без библиотеки форм. Тесты — Vitest + Testing Library + MSW; e2e — Playwright.

**Основания.** Только React-вариант даёт внешний вид MAX без ручной вёрстки. Маршрутизатор в памяти не трогает `location.hash`, где MAX передаёт `WebAppData`, и не зависит от серверных rewrite. Next.js отвергнут: SSR не нужен и требует Node-сервер.

**Недостатки.** React тяжелее Svelte; маршрут не сохраняется в URL — после перезагрузки страницы пользователь попадает на стартовый экран, что для мини-приложения приемлемо.

**Последствия.** Версии фиксируются `package-lock.json` в задаче FE-01; `@maxhub/max-ui` фиксируется точной версией (библиотека в версии 0.x). Глобальное состояние — только сессия и выбранная организация.

**Проверка.** FE-01: пустое приложение с MAX UI собирается, начальный JS ≤ 200 KB gzip (`npm run build` выводит размеры); MAX-03: открытие во всех четырёх клиентах.

**Условия пересмотра.** MAX UI не работает с React 18 или ломает CSP — тогда React 18 без MAX UI с собственными стилями по гайдлайну MAX.
