# ADR-034: Импорт документов из таблиц в браузере

Статус: принято. Дата: 2026-09-29. Версия архитектуры: 2.0.0.

## Вопрос
Как перенести уже существующий реестр сроков из Excel без ручного ввода каждой карточки (FR-24).

## Требования
Без новых сервисов и хранения файлов; CSP без сторонних скриптов; проверки строк те же, что у
формы; повтор после сбоя не создаёт дублей; предел пакетного создания — 30 документов.

## Варианты
1. Загрузка файла на сервер и разбор в core: хранение файла, библиотека разбора в Go, новые операции API.
2. Библиотека разбора таблиц в браузере: запрещена CSP при загрузке с CDN, увеличивает бандл.
3. Разбор в браузере собственным кодом и создание через существующий `POST /documents/batch`.

## Решение
Вариант 3. `shared/lib/spreadsheet.ts` читает `.csv` (разделитель `;`, `,` или табуляция, кавычки
RFC 4180, UTF-8 или Windows-1251) и `.xlsx` (ZIP: хранение и deflate через `DecompressionStream`,
первый лист по связям книги, общие и встроенные строки). `importRows.ts` сопоставляет столбцы по
заголовкам или по порядку, понимает даты `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, числа-даты Excel и «бессрочно»
и проверяет каждую строку правилами формы. Экран показывает строки с причинами ошибок и загружает
выбранные пакетами по 30 (до 1000 строк за раз). UUID строки создаётся один раз: повтор отправляет
только незагруженные строки с прежними идентификаторами.

## Основания
Файл не покидает устройство; сервер получает обычные идемпотентные запросы; нет новых зависимостей.

## Недостатки
Формат `.xls` не поддерживается; читается только первый лист; формулы — как сохранённые значения;
большой файл разбирается в памяти устройства.

## Последствия
Экран `/o/:orgId/documents/import`; вход — «Импорт из Excel» в разделе «Документы» и в настройках.

## Проверка
`importRows.test.ts`, `spreadsheet.test.ts`, `ImportPage.test.tsx` (T-FE-IMPORT), DATA-API `documents-batch`.

## Условия пересмотра
Потребность в `.xls`, нескольких листах или загрузке файлов больше нескольких мегабайт.
