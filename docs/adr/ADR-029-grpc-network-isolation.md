# ADR-029: Сетевая изоляция межсервисного gRPC

Статус: принято. Дата: 2026-09-20. Версия архитектуры: 2.0.0.
## Контекст
В v1.0.0 gRPC bot слушал все интерфейсы и был доступен из контейнера обратного прокси,
обращённого в интернет, хотя ADR-005 декларировал изоляцию.

## Решение
Межсервисный трафик проходит только по внутренней сети `data`.
bot-service получает фиксированный адрес в этой сети и слушает gRPC только на нём;
имя `bot-grpc` разрешается лишь во внутренней сети. Обратный прокси доступа к gRPC не имеет.

## Основания
Отсутствие аутентификации на межсервисном gRPC компенсируется сетевой изоляцией; декларация должна совпадать с конфигурацией.

## Недостатки
Фиксированный адрес привязывает конфигурацию к подсети Compose.

## Последствия
Проверка: из контейнера edge соединение с портом 9090 не устанавливается.

## Условия пересмотра
Переход на оркестратор с сетевыми политиками — замена фиксированного адреса политикой.
