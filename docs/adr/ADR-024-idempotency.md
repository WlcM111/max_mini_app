# ADR-024: Идемпотентность межсервисных операций

Статус: принято. Дата: 2026-09-20. Версия архитектуры: 2.0.0.
## Контекст
Повтор после таймаута не должен создавать второе бизнес-действие.

## Решение
- События core → reminders: ключ `event_id` (UUID v4), уникальный глобально; таблица `reminders.inbox_events`.
- Напоминания reminders → bot: ключ `rem:<period_id>:<account_id>:<days_before>`, зафиксированный исходным ТЗ; уникальность в пределах bot-service.
- Повтор с тем же ключом возвращает прежний результат и признак duplicate.

## Основания
Ключ выводится из предметных идентификаторов, поэтому не зависит от повторных запусков процессов.

## Недостатки
Смена периода документа меняет ключ: это намеренно, так как продление — новое напоминание.

## Последствия
Гарантия «не более одного сообщения на (период, получатель, отступ)» обеспечивается ключом,
а не отсутствием повторов передачи.

## Условия пересмотра
Изменение формата ключа требует согласованного обновления bot-service.
