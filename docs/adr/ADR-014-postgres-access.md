# ADR-014. Доступ к PostgreSQL из Go

**Вопрос.** Драйвер, генерация запросов, миграции.

**Варианты.** A. ORM (GORM) — скрытые запросы, сложнее контроль транзакций. B. pgx/v5 + sqlc (типобезопасный код из SQL) + goose (миграции SQL). C. database/sql + ручной SQL.

**Решение.** B. Миграции — файлы `services/<svc>/migrations/NNNNN_name.sql` в формате goose, встраиваются в бинарник (`embed`), таблица версий `core.goose_db_version` / `bot.goose_db_version`; выполняются командой `<svc> migrate up` ролью `*_migrator`. Запросы — `services/<svc>/internal/adapters/postgres/queries/*.sql`, код — `sqlcgen` (коммитится). Пул `pgxpool`: core — 20 соединений, bot — 8.

**Основания.** SQL остаётся явным и проверяемым; ошибки несоответствия схемы ловятся на генерации.

**Недостатки.** Динамические фильтры (статус, поиск) пишутся через `sqlc.narg` и `CASE`.

**Проверка.** `make gen-sql` без изменений в git; интеграционные тесты репозиториев.

**Условия пересмотра.** Нет.
