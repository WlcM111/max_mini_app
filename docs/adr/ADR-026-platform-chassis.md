# ADR-026: Общий технический каркас internal/platform

Статус: принято. Дата: 2026-09-20. Версия архитектуры: 2.0.0.
## Контекст
Конфигурация, логи, метрики, admin-эндпоинты, пул PostgreSQL и перехватчики gRPC одинаковы для трёх сервисов.

## Решение
Общий каркас в `internal/platform` содержит только технический код и не знает предметных типов.
Импорт из `internal/platform` в сервисы разрешён; обратный импорт запрещён и проверяется тестом.

## Основания
Однократная реализация снижает трудоёмкость и различия в поведении сервисов.

## Недостатки
Изменение каркаса затрагивает сборку всех сервисов: связность на уровне сборки, но не предметной области.

## Последствия
Общая бизнес-библиотека для сервисов не создаётся; общий репозиторный слой между схемами запрещён.

## Условия пересмотра
Расхождение требований сервисов к техническим компонентам — разделение каркаса по сервисам.
