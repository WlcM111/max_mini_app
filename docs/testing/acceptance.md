# Критерии приёмки и протокол

Версия 1.0.0 · 20.09.2026. Все пользовательские AC проходятся через интерфейс мини-приложения (BR-05). Локальная проверка — `http://localhost:8080/?mockUser=<id>`; проверка в MAX — стенд и протокол AC-MAX (`docs/max/max-integration-spec.md` §16).

| ID | Требования | Шаги | Ожидаемый результат |
|---|---|---|---|
| AC-01 | FR-01, FR-02 | открыть бота, нажать «Открыть»; закрыть и открыть по диплинку `?startapp=org_<uuid>` | мини-приложение открылось без ввода логина; показано имя пользователя MAX; диплинк открыл организацию |
| AC-02 | FR-03, FR-04 | «Добро пожаловать» → название, «Общепит», Санкт-Петербург → признаки (помещение, сотрудники, касса, алкоголь) → подсказки → даты для трёх документов → «Готово» | за ≤ 5 мин создана организация, предложено ≥ 8 типов с пометкой «модельные данные», дашборд показывает 3 документа со статусами |
| AC-03 | FR-05, FR-06, FR-15 | добавить свой документ с датой через 10 дней; открыть реестр; фильтр «Скоро истекает»; поиск по слову; изменить номер; удалить | статус «Скоро истекает, осталось 10 дней»; фильтр и поиск находят документ; изменения сохраняются; после удаления документ пропал из списка и сводки |
| AC-04 | FR-08, NFR-13 | в «Настройках» время напоминаний через 3 минуты; документ с окончанием через 7 дней и отступом 7; ждать | в чате с ботом сообщение «Через 7 дней заканчивается срок…», кнопка открывает карточку этого документа |
| AC-05 | FR-07 | в карточке «Продлить», новая дата окончания через год | статус «В порядке»; в истории два периода; ближайшее напоминание пересчитано |
| AC-06 | FR-09 | выключить напоминания; остановить бота в MAX; открыть «Настройки» | запланированные напоминания отменены; баннер «Бот остановлен» и кнопка «Открыть чат с ботом» |
| AC-07 | FR-10, FR-19 | owner: «Пригласить», роль editor, «Отправить в MAX» второму пользователю; второй принимает; owner меняет роль на viewer | второй видит организацию; владелец получил сообщение о присоединении; viewer не видит кнопок изменения; повторное открытие ссылки — «Приглашение уже использовано» |
| AC-08 | FR-11 | «Настройки» → «Экспорт в календарь» → «Скачать» | файл `.ics` сохранён средствами MAX; импортируется в календарь с событиями на даты окончания |
| AC-09 | FR-13 | в форме документа «Сканировать QR» на телефоне | распознанное значение подставлено в «Ссылка» (если `https://`) или «Номер»; на desktop/web кнопки нет |
| AC-10 | FR-14, NFR-06 | «Аккаунт» → «Удалить аккаунт» → подтвердить; открыть мини-приложение снова | данные удалены; новый запуск начинается с «Добро пожаловать» |
| AC-11 | FR-17 | выполнить `seed-demo` и `review-token issue` для editor и viewer; запрос `GET /me` с каждым токеном | демо-организация с 12 документами (пометка «тестовые данные»); роли editor и viewer соответственно |
| AC-12 | NFR-08, SUB-05…07 | на чистой машине: `git clone`, `docker compose up -d --build`, открыть `http://localhost:8080/?mockUser=1001` | сборка ≤ 5 мин без загрузки базовых образов; все сервисы `healthy`; онбординг проходит; `docker compose down` и `up -d` сохраняют данные |
