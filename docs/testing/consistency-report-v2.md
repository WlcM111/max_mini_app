## 2. Проверки, которые выполнить не удалось

| Проверка | Причина | Что осталось неподтверждённым |
|---|---|---|
| `docker build`, `docker compose up` | Docker в среде подготовки отсутствует, реестр образов недоступен | работоспособность образов и автономного compose |
| `buf breaking` относительно v1.0.0 | тег contracts-v1.0.0 в репозитории отсутствует (история git не передавалась) | формальная проверка совместимости messaging.proto; изменён только комментарий |
| Сквозной сценарий трёх сервисов | core-service и bot-service не реализованы | интеграция системы целиком |
| Нагрузочные измерения | требуется развёрнутая система | пересчитанные оценки раздела 17 ТЗ |
| Проверка внутри MAX | внешний блокер: привязка URL и токен | запуск мини-приложения в мессенджере |
