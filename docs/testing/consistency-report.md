# Отчёт проверки согласованности

Версия 1.0.0 · 20.09.2026. Проверки выполнены по пункту verification_and_acceptance мета-инструкции. «Скрипт» — автоматическая проверка в изолированной среде без развёртывания; «анализ» — сверка по документам. Результат «пройдено» означает, что известных противоречий нет; это не утверждение об абсолютной безошибочности.

## 3. Несоответствия, найденные и исправленные при проверке

| Найдено | Исправление |
|---|---|
| Правило «не отправлять остановившим бота» было и в core, и в bot | оставлено только в bot (`recipient_stopped`); обновлены long-operations, spec §8, комментарий proto |
| Замер сборки учитывал загрузку базовых образов, что кейс исключает | `measure_build.sh` загружает базовые образы заранее |
| Образ core не копировал каталог `demo` для встраивания | добавлен `COPY demo` в `services/core/Dockerfile` |
| Скрипт DATA-API не проверял тип содержимого и обязательные поля | скрипт дополнен |
| Групповые строки матрицы скрывали отдельные требования | развёрнуты построчно |
| Нет e2e-файла для сценария участников; не было `vite-env.d.ts` | добавлены в структуру и дерево |
| `type` проблем ссылался на несуществующий домен | заменён на `urn:vovremya:problem:<код>` |
| Форма продукта «мини-приложение» не была закреплена требованием | добавлены BR-05 и раздел «Форма продукта» в ADR-001 |

## 4. Что не проверено инструментально и как проверить

В изолированной среде нет Go, protoc/buf, PostgreSQL и Docker. Процедура REPO-01/CORE-01 на машине разработчика:

```sh
buf lint && buf generate                                  # компиляция proto
docker compose config -q                                  # схема compose
docker compose up -d postgres core-migrate bot-migrate    # применение DDL на PostgreSQL 18
docker compose logs core-migrate bot-migrate              # ожидается "successfully migrated"
npx @redocly/cli@latest lint openapi.yaml                 # строгая проверка OpenAPI 3.1
```

Возможности MAX, отмеченные как неподтверждённые (U-01…U-09), проверяются задачами MAX-01…MAX-03 до реализации зависящих от них экранов.
