## 5. Браузерные E2E (BLOCKED)

Сценарии написаны: `frontend/e2e/launch.spec.ts`, `documents.spec.ts`, `members.spec.ts`,
`network.spec.ts`; конфигурация — `frontend/playwright.config.ts` (профили Pixel 7,
iPhone 13, узкий desktop).

**Выполнить в этой среде невозможно**: `npx playwright install chromium` завершается ошибкой —
загрузка браузеров идёт с внешнего CDN, недоступного из среды сборки. Это внешнее ограничение
среды, а не дефект приложения.

Воспроизведение на машине с доступом в интернет:

```sh
cd frontend && npm ci && npx playwright install --with-deps chromium
cd .. && docker compose up -d --build
E2E_BASE_URL=http://localhost:8080 npm --prefix frontend run e2e
```
