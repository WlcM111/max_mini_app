## 3. Изученный исходный код backend

Прочитаны публичный слой и контракты трёх сервисов в объёме, необходимом для интеграции:
`services/core/internal/adapters/httpapi` (маршруты, проблемы, ограничители), `internal/app`
(сценарии, коды ошибок, идемпотентность), `services/reminders` и `services/bot` (контракты
gRPC, состояния канала, буфер stub-сообщений), `test/e2e` (стенд, переменные окружения).
