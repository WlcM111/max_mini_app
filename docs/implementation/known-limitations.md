# Известные ограничения проекта

Версия 1.0.0 · 24.09.2026. Только фактически обнаруженные ограничения.

## 1. Ограничения текущей реализации

| Ограничение | Влияние | Планируемое решение |
|---|---|---|
| `@maxhub/max-ui` зафиксирован на 0.2.0 | недоступны компоненты версий 0.3–0.5 | переход на React 19 + max-ui 0.5.0 отдельным решением (пересмотр ADR-003), см. C-FE-01 |
| Офлайн-очередь изменений не реализована | без сети изменения не сохраняются, пользователь видит «Нет соединения» и кнопку «Повторить» | предусмотрено архитектурой §10, изменение не планируется |
| Оптимистичных обновлений нет | после сохранения данные перечитываются с сервера | сознательное решение: сервер — источник статусов |
| Часовой пояс карточки берётся из профиля организации отдельным запросом | лишний запрос при открытии карточки по диплинку | добавить пояс в ответ документа (требует изменения контракта) |
| Ограничители частоты core хранятся в памяти процесса | при нескольких экземплярах core пределы считаются раздельно | вынести во внешнее хранилище при масштабировании |

## 2. Внешние ограничения платформы MAX

| Ограничение | Источник | Следствие |
|---|---|---|
| `downloadFile` работает только внутри клиента MAX | F-20 | в вебе экспорт открывается через `openLink` |
| `HapticFeedback` недоступен в desktop и web | F-25 | отклик только на iOS и Android |
| Диплинк шеринга `https://max.ru/:share` не работает на десктопе | F-07 | запасной путь — копирование ссылки в буфер |
| Подключение Mini App возможно только через кабинет партнёра MAX | F-02, F-04 | URL и токен задают организаторы (MAX-03) |
| `payload` диплинка ≤ 512 символов, ограниченный алфавит | F-05 | токены приглашений укладываются в ограничение |

## 3. Ограничения среды проверки

| Ограничение | Что не выполнено | Как воспроизвести |
|---|---|---|
| Docker в среде отсутствует | `docker compose up -d --build`, сборка образов, проверка запуска через Compose | инструкция README §4; состав compose проверен статически (127 проверок) |
| Браузеры Playwright не загружаются (внешний CDN недоступен) | браузерные E2E не выполнялись | `npx playwright install --with-deps chromium`, затем `npm run e2e` |
| Токен бота MAX не выдан | режим `BOT_MODE=live`, реальные webhook и кнопка `open_app`, запуск внутри клиентов MAX | `docs/operations/max-miniapp-setup.md` |

## 4. Неподтверждённые условия

- Работа внутри клиентов MAX на iOS, Android, desktop и web (PLAT-08, AC-01…AC-11 на стенде MAX).
- Поведение при реальных задержках сети мобильного клиента MAX.
- Нагрузочный профиль (`make load`) — требует Docker.
